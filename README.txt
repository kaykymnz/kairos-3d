LAYER LAB — SITE DEMO

Como abrir:
1. Extraia a pasta do ZIP.
2. Abra index.html no navegador (ou use a extensão Live Server no VS Code).

Arquivos:
- index.html: estrutura das páginas de catálogo e produto.
- style.css: layout responsivo e identidade visual.
- script.js: busca, filtros, ordenação, carrinho e navegação.
- assets/: imagens recortadas das referências enviadas.

Antes de publicar:
- Troque 5500000000000 pelo número real do WhatsApp (DDI + DDD + número, somente dígitos).
- Troque https://instagram.com/ pelo perfil real da loja.
- Atualize preços, descrições, imagens e disponibilidade conforme os produtos reais.
- O catálogo contém 6 cards e o destaque do dragão (7 peças no total).

Observação: os recortes dos produtos foram extraídos das imagens de referência fornecidas, então a resolução é limitada à captura. Substitua por renders/fotos originais em alta resolução quando disponíveis.
